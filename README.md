# SAP BTP Guidance Framework

Documentation generated from the SBN IT Architect Day presentation (April 9, 2024) by Katrin von Ahsen, Chief Product Expert SAP BTP. This set covers the framework's structure, reference architectures, the Extension Architecture Guide, and the three core methodologies — for architects, developers, and administrators adopting SAP BTP.

## Where to Start

- *If you are an IT Architect* new to SAP BTP: start with [docs/01-guidance-framework-overview.md](docs/01-guidance-framework-overview.md) to understand the full landscape, then read [docs/04-methodologies.md](docs/04-methodologies.md) before beginning any design work.
- *If you are designing or reviewing an extension* to an SAP application: go directly to [docs/03-extension-architecture-guide.md](docs/03-extension-architecture-guide.md).
- *If you are looking for a solution template* to adapt for your scenario: read [docs/02-reference-architectures.md](docs/02-reference-architectures.md) and follow the pointer to SAP Discovery Center.
- *If you are a developer* getting started on SAP BTP: start with [docs/01-guidance-framework-overview.md](docs/01-guidance-framework-overview.md) §4 (Guidance for Developers) and [docs/04-methodologies.md](docs/04-methodologies.md).
- *If you need to brief a stakeholder* in 10 minutes: read [docs/01-guidance-framework-overview.md](docs/01-guidance-framework-overview.md) §1–§2 and open the architecture diagram.
- *If you are new to this topic*: read the documents in order from 01.
